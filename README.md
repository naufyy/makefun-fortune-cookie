The Legacy Function Nobody Owns: a tiny Python program that writes one line of fortune-cookie wisdom to /output/entry.txt. The line is about orphaned legacy code. The moment you fix a single line of it, git blame shows your name, and "blame" means both the tool and the responsibility you now carry.

Why this line: of the six candidates, it is the only one that pairs a cookie-style prophecy ("will gladly make it yours") with a scene every developer has lived, and its "blame" pun works both as the tool and as the responsibility. The others lean either too abstract (estimates, merge conflicts) or too tied to a single situation (Friday deploys, on-call, TODOs) to read as timeless wisdom.

## Run it

```sh
python3 main.py
```
